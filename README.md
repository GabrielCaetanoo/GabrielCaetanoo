**🩺 MedTranscribe — Medical Transcription SaaS**
Founder & sole developer. Converts medical consultation audio into structured clinical records (SOAP/clinical). Built with **Next.js**, **Supabase** (Postgres + Row Level Security), **Whisper API** for transcription and the **Claude API** for clinical structuring, with **Stripe** billing. Multi-tenant modeling with profiles, clinics, patients, consultations and audit logs.
